# 工程路线图

[English](ROADMAP.md) | [简体中文](ROADMAP.zh-CN.md)

本文档记录 Watermark Removal Lab 的计划实施顺序。它不是发布日期表，也不表示某个里程碑已经完成。面向产品展示的 README 文件不会包含开发路线或开发状态章节。

## 交付原则

- 除非有明确决策记录说明原因，否则按顺序完成各里程碑。
- 定位、掩膜细化、补全、评测和展示始终保持可替换。
- 先完成无界面核心和 CLI，再开发桌面应用。
- 添加模型运行时之前，必须先保留 OpenCV 无模型基线。
- 集成或分发具体模型产物之前，先完成模型与数据许可证登记。
- 批量处理必须编排相同的单项流水线，不得重新实现第二套算法。
- 测试与示例必须使用合成、自制或明确授权的素材。

## 能力轨道

路线图由八个主要里程碑以及贯穿式批量处理和桌面端能力轨道组成：

| 轨道 | 目的 |
|---|---|
| M1–M6 | 图片定位、补全、评测与部署 |
| M7–M8 | 视频工程基线与时序一致处理 |
| B1–B4 | 逐步复用各里程碑流水线的批量编排 |
| D1 | M1/B1 CLI 契约通过验证后的桌面端适配器 |

批量处理不作为孤立的 M9，因为它必须随各媒体流水线共同演进：

- **B1，对应 M1：** 确定性的顺序图片批处理；
- **B2，对应 M2–M4：** 可恢复、资源感知的模型批处理；
- **B3，对应 M5–M6：** 聚合评测与服务队列任务；
- **B4，对应 M7–M8：** 长时间视频与混合媒体批处理。

详细批量处理契约见 [BATCH_PROCESSING.zh-CN.md](BATCH_PROCESSING.zh-CN.md)。

桌面端轨道只有在 M1 单图和 B1 批量 CLI 退出门槛通过后才开始。Qt、Electron 或其他框架通过聚焦原型和新的 ADR 选择，不通过修改无界面核心来决定。

## M1：OpenCV 图片基线

### 目标

交付无模型图片去除 CLI，使用用户提供的边界框或二值掩膜，并通过 OpenCV Telea/Navier-Stokes 完成补全。

### 必需范围

- 显式处理 RGB/BGR 的图片 IO；
- 独立 Alpha 处理；
- 边界框生成掩膜与外部掩膜输入；
- 掩膜校验与可配置膨胀；
- Telea 和 Navier-Stokes 后端；
- 仅在掩膜范围内回贴；
- 安全输出行为和结构化失败；
- 通过 B1 实现确定性的顺序图片批处理；
- 聚焦的单元测试和 CLI 集成测试。

### 退出门槛

- 单图和 B1 批量命令满足 [M1 规范](milestones/M1-opencv-image-baseline.zh-CN.md)；
- 有损编码前，最终细化掩膜外像素保持不变；
- Alpha 保持不变；
- 无效边界框、掩膜、输出冲突和写入失败均有测试；
- 不需要网络访问或模型下载；
- 文档仅包含已授权或合成示例。

## M2：LaMa 图片补全

### 目标

在保持 M1 请求、结果和掩膜契约的前提下，增加基于模型的图片补全器。

### 必需范围

- 根据最终掩膜计算边界框；
- 扩展可配置 padding 的局部裁剪；
- 运行完成审计的 PyTorch 或 ONNX LaMa 产物；
- 仅在最终掩膜内回贴；
- 支持显式 CPU/GPU provider 和模型缓存；
- 比较 OpenCV 与 LaMa 的质量、延迟、RAM 和 VRAM；
- 通过 B2 增加 provider 感知调度和可恢复模型任务。

### 退出门槛

- 实现满足 [M2 规范](milestones/M2-lama-image-inpainting.zh-CN.md)；
- 具体模型与权重许可证已登记到 `MODEL_LICENSES.md`；
- 模型下载和完整性校验由用户明确触发；
- provider 缺失和内存不足具有可操作错误；
- 局部裁剪与全图边界情况有测试；
- 不安装模型依赖时仍可使用 OpenCV。

## M3：SAM/SAM 2 交互式图片分割

### 目标

把用户点击和边界框转换为可编辑的候选掩膜，再进行补全。

### 必需范围

- 正负点击；
- 边界框提示；
- 带分数的多个候选掩膜；
- 预览、选择和细化契约；
- 图片 embedding 缓存；
- `提示 → 分割 → 细化 → 补全` 集成；
- B2 支持已保存提示或掩膜的清单输入。

### 退出门槛

- 不把 SAM/SAM 2 描述或实现为自动理解水印语义的检测器；
- 重复提示可以复用图片 embedding；
- 提示坐标与变换后图片坐标具有测试；
- 具体代码与 checkpoint 许可证、哈希已登记；
- 交互适配器与核心分割契约保持分离。

## M4：图片自动定位

### 目标

生成可供掩膜生成和补全使用的水印区域建议。

### 必需顺序

1. 模板匹配；
2. 多尺度归一化互相关；
3. 半透明文字和边缘响应启发式；
4. 通用边界框检测器；
5. 使用 SAM 细化边界框/点建议。

候选视觉类别包括 `corner_logo`、`text_strip`、`timestamp`、`centered_wordmark`、`translucent_badge` 和 `custom_overlay`。

### 退出门槛

- 自动建议暴露置信度与来源；
- 在干净图片上测量误触行为；
- 批量推理可以安全复用检测器和 embedding 缓存；
- 不引入针对付费预览水印的平台专用检测器；
- 用户可以审查、覆盖或拒绝自动建议。

## M5：多流水线评测

### 目标

在可复现条件下比较可替换的定位、分割和补全组合。

### 必需比较

- ManualBox + RuleMask + OpenCV；
- ManualBox + SAM + LaMa；
- TemplateDetector + SAM + LaMa；
- Detector + SAM + LaMa。

### 必需指标

- 掩膜 IoU；
- 水印残留或残留检测率；
- 干净图片误触率；
- 最终掩膜外像素变化；
- 边界颜色误差；
- 方法上有效时使用 SSIM 和 LPIPS；
- 延迟与吞吐量；
- 峰值 RAM 和 VRAM。

### 退出门槛

- 指标定义、数据划分、排除项和硬件环境均有记录；
- B3 聚合指标不会隐藏失败项；
- 保留原始逐项结果；
- 基准比较使用等价输入与掩膜条件。

## M6：图片部署

### 目标

通过服务和交互适配器暴露经过评审的图片流水线。

### 必需范围

- FastAPI 图片接口；
- Gradio 或 Web 交互；
- CPU 与 CUDA 容器；
- ONNX Runtime provider；
- 模型缓存、队列、并发、超时、取消和资源限制；
- 异步任务与状态接口；
- B3 队列集成，并复用相同的批量请求/结果契约。
- 如果已经启动桌面端轨道，为选定的 D1 桌面适配器提供生产打包与分发。

建议接口：

- `/v1/image/detect`；
- `/v1/image/segment`；
- `/v1/image/inpaint`；
- `/v1/image/remove`；
- 异步任务提交与状态接口。

### 退出门槛

- 同步与队列行为共享应用服务；
- 桌面端、Web 和 API 适配器复用相同的应用与批量服务；
- 上传、输出、超时和取消具有有界资源行为；
- API 不暴露服务器本地任意路径；
- 部署包包含适用许可证和第三方声明。

## M7：视频水印去除基线

### 目标

为固定视频覆盖物提供明确标注为工程基线的实现。

### 必需范围

- FFmpeg 解码；
- 首帧固定边界框或静态掩膜；
- 每帧运行 OpenCV 或 LaMa；
- 兼容时透传原音频；
- 重新编码输出；
- 处理 FPS、分辨率、像素格式、旋转元数据、编码器和失败；
- 可检查点恢复的长任务和 B4 视频批量任务。

### 退出门槛

- 固定角标、时间戳和静态文字具有覆盖示例；
- 验证输出时长、帧数、时间信息、旋转和音频；
- 中断时不会把不完整文件呈现为最终输出；
- 文档明确说明可能出现时序闪烁；
- 不把实现描述为具备时序一致性。

## M8：时序一致视频流水线

### 目标

加入面向跨帧一致性的掩膜传播与视频补全行为。

### 必需范围

- 首帧提示；
- SAM 2 传播或跟踪；
- 场景切换检测；
- 时序掩膜平滑；
- 遮挡与重新出现行为；
- 具备时序一致性的视频补全；
- 有界 GPU 内存和缓存生命周期；
- B4 恢复与混合时长调度。

### 必需指标

- 相邻帧掩膜 IoU；
- 轨迹抖动；
- 光流对齐误差；
- flicker；
- 处理 FPS 与实时倍率；
- 峰值 RAM 和 VRAM。

### 退出门槛

- 场景切换、遮挡、掩膜漂移和缓存重置行为均有测试；
- 时序质量必须实际测量，不能由逐帧质量推断；
- 长任务可在定义的检查点取消和恢复；
- 限制与不支持内容均有记录。

## 批量处理能力轨道

### B1：顺序图片批处理

- 确定性的输入顺序；
- 目录发现与版本化清单输入；
- 共享默认值与逐项边界框/掩膜覆盖；
- 预检校验和输出冲突检测；
- 逐项失败隔离；
- 原子输出、机器可读结果和最终汇总；
- 仅使用一个 worker。

### B2：可恢复模型批处理

- provider 感知的有界并发；
- 模型与 embedding 缓存复用；
- 输入与配置指纹；
- 显式恢复、重试、快速失败和覆盖策略；
- 确定性校验失败不得自动重试。

### B3：评测与服务批处理

- 聚合成功、失败、跳过和取消数量及对应指标；
- 保留逐项原始指标；
- 异步队列与状态契约；
- 配额、超时、取消和资源限制；
- CLI、API 和桌面端复用同一编排服务。

### B4：视频与长任务批处理

- 视频检查点记录；
- 时长与资源感知调度；
- 安全取消与重启；
- 清理部分产物并保证最终输出原子性；
- 只有图片和视频单项流水线都稳定后，才支持混合媒体清单。

## 桌面应用能力轨道

### D1：CLI 验证后的桌面端适配器

进入门槛：

- M1 单图和 B1 批量 CLI 退出门槛通过；
- 请求、结果、进度、取消和错误契约具有集成测试；
- 无界面核心无需导入 GUI 框架即可运行。

必需范围：

- 开展聚焦的 Qt/Electron/其他方案原型，比较打包、图片交互、Python/模型集成、分发体积、更新与崩溃隔离；
- 通过新的 ADR 记录选定框架和权衡；
- 打开已授权图片并选择边界框或掩膜；
- 预览最终掩膜与处理前后结果；
- 通过公共应用服务执行单图和 B1 批量操作；
- 暴露进度、取消、结构化错误、覆盖策略和批次汇总；
- 只有对应里程碑达到退出门槛后，才加入 SAM/LaMa/视频界面。

退出门槛：

- 桌面适配器不复制算法或批量编排逻辑；
- 至少一个目标平台的软件包可以复现构建且具有文档；
- 模型缓存与可选运行时仍由应用层管理；
- 软件包包含适用许可证和第三方声明；
- 关闭或取消 UI 不会发布不完整的最终输出。

## 变更控制

- 详细里程碑规范保存在 `docs/milestones/`。
- 重大架构变更必须新增 ADR。
- 可以不通过 ADR 提高里程碑退出门槛。
- 调整里程碑顺序、降低安全边界或改变核心依赖方向时，必须显式评审。
