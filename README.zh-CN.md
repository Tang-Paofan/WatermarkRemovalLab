# Watermark Removal Lab

[English](README.md) | [简体中文](README.zh-CN.md)

基于 OpenCV、SAM/SAM 2、LaMa、ONNX Runtime 和 FFmpeg 的图片与视频可见水印定位、分割、补全、评测和部署实验平台。

> [!IMPORTANT]
> 本项目仅用于您拥有、创建或已获授权编辑的图片和视频。项目不用于绕过版权保护、来源证明系统、平台声明或付费预览水印。

## 媒体范围

| 媒体 | 研究范围 |
|---|---|
| 图片 | 可见覆盖物定位、掩膜细化、补全、评测与输出 |
| 视频 | 固定及移动可见覆盖物的定位、传播、补全、评测与输出 |

## 项目目标

Watermark Removal Lab 是一个工程实践和学习项目，用于探索：

- 可见水印检测与交互式提示；
- 掩膜分割、细化与传播；
- 图片补全和具有时序一致性的视频补全；
- OpenCV 与模型方法的质量基线；
- ONNX Runtime 模型部署与性能调优；
- FFmpeg 视频解码、编码与音频透传；
- 对质量、延迟和资源占用进行可复现评测。

项目采用可替换的流水线：

```text
检测 / 提示
    → 分割 / 定位
    → 细化掩膜
    → 补全
    → 评测
    → 输出
```

定位与补全保持解耦，使检测器、分割器、掩膜细化器、补全器和质量评估器可以独立演进。

## 设计原则

- 通用 MVP 优先支持用户点击、框选或提供掩膜。
- SAM/SAM 2 用于提示分割、掩膜细化和跟踪，不默认作为理解水印语义的检测器。
- LaMa 处理带有留白的局部裁剪，回贴时仅替换细化掩膜内的像素。
- 保留 OpenCV Telea 和 Navier-Stokes 作为透明、无模型的基线。
- 在实现并评测时序一致性之前，如实将逐帧视频处理描述为工程基线。
- 模型资源缓存在 Git 仓库之外，并分别审计代码、权重和数据集许可证。
